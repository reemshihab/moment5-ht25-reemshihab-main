 # DT084G - Moment 5: Sveriges Radio webbapplikation

Detta projekt är en webbapplikation som använder Sveriges Radios öppna API för att hämta information om radiokanaler och deras programtablåer.

### Funktioner:
- Visar en lista med radiokanaler till vänster.
- Vid klick på en kanal visas dagens programtablå.
- Möjlighet att välja hur många kanaler som ska visas.
- En radio-spelare som spelar upp vald kanal via deras live-ström.

### Tekniker som används:
- HTML, CSS och JavaScript
- Fetch API och async/await för att hämta data från Sveriges Radios öppna API
- Dynamisk uppdatering av DOM med JavaScript
